# SENA_Asset - ระบบบริหารจัดการและตรวจสอบครุภัณฑ์

ระบบบริหารจัดการทะเบียนครุภัณฑ์และบัญชีรายการตรวจสอบครุภัณฑ์ประจำปี พัฒนาสำหรับ **สำนักงานส่งเสริมการเรียนรู้ประจำอำเภอเสนา (สกร.ระดับอำเภอเสนา) จังหวัดพระนครศรีอยุธยา**

---

## 🌟 ฟีเจอร์เด่นของระบบ (Key Features)

1. **แดชบอร์ดภาพรวมอัจฉริยะ (Dashboard & Analytics)**
   - แสดงสถิติครุภัณฑ์แบบเรียลไทม์: ครุภัณฑ์ทั้งหมด, ใช้ได้, ชำรุด, เสื่อมคุณภาพ
   - กราฟิกสถิติวิเคราะห์ด้วย Chart.js (แยกตามสถานะ, หมวดหมู่, วิธีการได้มา, และสถานที่ใช้งาน)
   - รายการครุภัณฑ์ล่าสุดและการตรวจนับ

2. **ทะเบียนครุภัณฑ์ (Equipment Registry)**
   - แสดงข้อมูลแบบเต็มหน้าจอ (Full-width) รองรับทั้ง **มุมมองตาราง (Desktop Table)** และ **มุมมองการ์ด (Mobile Cards)**
   - คลิกที่ **ไอคอนรูปเปิดตา 👁️** เพื่อเปิดหน้าต่าง **ป๊อปอัปรายละเอียดครุภัณฑ์ (Detail Popup Modal)**
   - ถ่ายรูป/แนบรูปภาพครุภัณฑ์ พร้อมระบบบีบอัดและย่อรูปภาพอัตโนมัติ (ขนาดไฟล์เฉลี่ย < 70KB)
   - สร้าง QR Code ประจำครุภัณฑ์อัตโนมัติ พร้อมฟังก์ชันสั่งพิมพ์สติกเกอร์ QR Code

3. **บัญชีรายการตรวจประจำปี (Annual Inspection Checklist)**
   - ตรวจนับและบันทึกสถานะพัสดุประจำปีงบประมาณ (ใช้ได้, ชำรุด, เสื่อมคุณภาพ, สูญไป, ไม่ใช้)
   - อัปเดตสถานะแบบ AJAX รวดเร็ว ไม่ต้องรีเฟรชหน้าเว็บ
   - ฟังก์ชัน **นำเข้าข้อมูลจากปีก่อนหน้า** เพื่อนำมาตรวจนับซ้ำในรอบปีงบประมาณถัดไป (เช่น ปี 2570)
   - แสดงผลแถบสรุปความก้าวหน้า (Progress Bar) และสถิติการตรวจนับ

4. **ระบบนำเข้าและส่งออกข้อมูล (Data Import & Export)**
   - นำเข้าข้อมูลจากไฟล์ Excel (.xlsx, .xls) หรือ CSV
   - ส่งออกข้อมูลเป็นไฟล์ Excel (.xls / .csv) พร้อมใช้งาน
   - ระบบโหลดชุดข้อมูลตัวอย่าง (Seed Data) สำหรับเริ่มต้นใช้งาน

5. **รองรับโทรศัพท์มือถือเต็มรูปแบบ (Mobile First / Responsive Design)**
   - ออกแบบ UI สวยงาม ทันสมัยด้วย Tailwind CSS
   - เหมาะสำหรับการถือสมาร์ตโฟนหรือแท็บเล็ตเดินตรวจนับครุภัณฑ์ในสถานที่จริง

6. **ระบบความปลอดภัยและการตั้งค่าผู้ใช้ (Auth & Settings)**
   - ระบบล็อกอิน/ออกจากระบบของเจ้าหน้าที่
   - จัดการข้อมูลผู้ใช้งาน ตั้งค่าชื่อ-นามสกุล, Username และรหัสผ่าน
   - ตั้งค่าชื่อองค์กร และสามารถอัปโหลดเปลี่ยนโลโก้ระบบได้ตามต้องการ

---

## 💻 เทคโนโลยีที่ใช้ (Tech Stack)

- **Backend:** PHP 7.4+ / PHP 8.x
- **Database:** MySQL / MariaDB (UTF-8 mb4)
- **Frontend:** Tailwind CSS (CDN), Font Awesome 6, Chart.js 4, Google Fonts (Prompt)
- **Image Processing:** PHP GD Library (Auto Web/JPG Compression)
- **Excel/Data Handling:** SheetJS (CDN) + Native PHP CSV Parser

## 🚀 ขั้นตอนการติดตั้ง (Installation)

1. **คัดลอกไฟล์ลงใน Web Server** (เช่น MAMP หรือ XAMPP):
   ```bash
   # เส้นทางโฟลเดอร์ เช่น htdocs/SENA_Asset
   git clone https://github.com/2538most1995/sena_asset.git
   ```

2. **ตั้งค่าฐานข้อมูล (Database Setup)**:
   - เปิด phpMyAdmin หรือ MySQL Client
   - สร้างฐานข้อมูลชื่อ `sena_asset`
   - รันสคริปต์ SQL จากไฟล์:
     1. `database/setup.sql` (สร้างตาราง)
     2. `database/seed_data.sql` (ข้อมูลเริ่มต้นและข้อมูลตัวอย่าง)

3. **ตั้งค่าการเชื่อมต่อฐานข้อมูล**:
   - ตรวจสอบไฟล์ `config/database.php`:
     ```php
     define('DB_HOST', 'localhost');
     define('DB_NAME', 'sena_asset');
     define('DB_USER', 'root');
     define('DB_PASS', 'root'); // หรือเว้นว่างตามการตั้งค่าของเซิร์ฟเวอร์
     ```

4. **เข้าสู่ระบบใช้งาน**:
   - เปิดเบราว์เซอร์ไปที่: `http://localhost/SENA_Asset/`
   - ข้อมูลเข้าสู่ระบบเริ่มต้น:
     - **ชื่อผู้ใช้:** `admin`
     - **รหัสผ่าน:** `admin123`
